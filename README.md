# Sistema Monolítico

Sistema desenvolvido para caso de estudo sobre sistema monolítico, aplicando conceitos de clean architecture, DDD e sistema monolítico modularizado, buscando construir um sistema de fácil mudança de arquitetura para escalar, como para microserviços, por exemplo.

#### Comandos para realizar a instalação das dependências, executar os testes e webserver para testes de API

#### Instalar dependências:
`npm install --verbose --no-fund --no-audit`

`npm install --verbose --no-fund --no-audit sequelize sqlite3`

#### Executar testes unitários, integração e E2E:
`npm test` / `npm run test`

#### Executar webserver api
`npm run server`
